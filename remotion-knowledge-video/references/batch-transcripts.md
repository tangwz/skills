# 逐字稿分段与批量输出

每个有效口播段对应独立内容动画、Composition 和从零开始的时间轴；一片内可有多个 `Sequence`。只在用户要求视频文件或编码时逐段导出，一个长 Composition 或合集不能代替多文件交付。

## 分隔线与原稿

默认按正文顶层的 Markdown 分隔线切分，如独占一行的 `---`、`***`、`___`；建议上下留空行。无分隔线作为一个视频，用户指定其他边界时从其要求：

```markdown
# Expansion

First narration block.

---

# Activation

Second narration block.
```

使用已有解析器的 [CommonMark 块结构](https://spec.commonmark.org/0.31.2/#thematic-breaks) 和源位置，按原文切片。围栏/缩进代码、HTML、引用或列表内横线、Setext 标题下划线不作为顶层边界；不能用 `split("---")` 或渲染后的 HTML 代替原稿。

文件头只有明确声明为元数据或符合项目已知字段与值类型时才跳过。核对解析器猜出的 front matter，保留 `Speaker: First sentence` 等 YAML 形状的口播。连续或首尾横线产生的空段注明跳过，不注册、不编码。

原稿标题、镜头提示和代码用于制作，仅实际念出的内容进入估时。递归读取列表、引用等容器内的正文口播，保持源顺序；代码和 HTML 块不默认视为口播。无口播段单独标记，明确要求时才制作，不捏造语音时长。保留有效短段，不自行合并、改稿、补过渡或跨段提前展示结论。

## 批次清单

新 session 使用未占用的批次名称、组件与 Composition ID，按原稿稳定编号；同一 session 继续本批次时沿用对应关系。各段有独立时序，共用品牌层只保留一份。

清单沿用项目格式，记录：

| 对应关系    | 记录内容                                                  |
| ----------- | --------------------------------------------------------- |
| 源段 → 作品 | 顺序/编号、原稿区间与原文、组件、Composition ID、输出路径 |
| 作品 → 时间 | 口播时长依据、预算与帧数、音频源区间和片内偏移            |
| 作品 → 状态 | 跳过/预览/编码状态、实际文件与媒体时长                    |

恢复渲染前核对完整有序计划，只重试未完成段并保留已验证文件。计划增删、重排或改动使用新的输出批次，避免混版；本 session 的内容组件与编号仍可沿用。

## 各片口播与录音

逐段应用 [口播时序](narration-timing.md)，分别估时，不能平分整篇时长或等长切割。复用共用 fps，每片从零计时，不使用整篇累计秒数作为片内起点或片长。

各段默认是讲解片段，不重复加频道片头片尾；章节标题伴随口播，整期品牌开场与总结只在适用的首末段且预算允许时安排。稳定区使用本段总结或停顿，不借用下一段，不机械延长视频。

逐段录音逐个配对；整篇录音的切点须由同版确认时码或试听确定，Markdown 边界本身不是音频边界。不要按字数比例冒充实测切点或切断词句，边界停顿只归入一次，清单注明保留静音与排除区间。

源锚点须属于本段音频区间，只平移并加片内偏移一次：

```text
retainedAudioSeconds = sourceAudioEndSeconds - sourceAudioStartSeconds
clipCueSeconds = sourceCueSeconds - sourceAudioStartSeconds + audioStartSeconds
videoEndSeconds = audioStartSeconds + retainedAudioSeconds + extraTailSeconds
```

额外尾段默认零。原始录音不改写，使用项目媒体方式引用区间或输出衍生文件；字幕仍从项目规则。

## 实现与交付

追加全部独立 Composition，Studio 可逐片选择。背景放每片外层，由该片全局帧驱动，片内跨场景连续，稳定区独立设置；字体、品牌、安全区和语义色共用，内容布局各自设计。

文件请求逐段编码到本批次独立路径，可用已有批量工具并按资源并行。逐个核对实际文件、可解码性、帧率与时长；命令启动或路径存在不代表成功。失败段记录并单独重试，不把部分成功报告为整批完成。代码或预览请求不扩展到编码。

按原稿顺序交付清单，检查无漏段、重复或跨段混入，逐片核对预算与讲解词动作。抽查各片首个信息画面、核心变化、收尾及最长段中部；文件交付要求全部制作段有独立可播放产物，未制作的无口播段标明。
