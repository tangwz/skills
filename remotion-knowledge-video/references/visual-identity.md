# 视觉与品牌规范

默认方向为深色知识图解、低对比网格、清晰语义色、克制光晕。以下数值是默认值，不覆盖用户已有品牌；可执行的模板参数统一维护在 `assets/template/video-style.ts`，项目采用后以自身共用配置为准。

## 画布与背景

- 默认横屏 1920 × 1080、60 fps；内容安全边距 90px。旧视频保留既有帧率，除非用户明确要求转换。
- 默认画布采用近黑色 `#030404`。接入已有项目时由确认后的共用品牌配置提供背景色，避免旧主题与新组件各自定义相互冲突的值。
- 网格以 20px 次网格与 80px 主网格区分尺度，白线透明度分别约 0.045 与 0.15。长文字和复杂公式场景可进一步降低网格透明度。
- 网格默认沿 -35° 方向以 20px/s 确定性移动，速度按 1080p 画布定义，随画布统一缩放。`grid.animate`、`speed`、`angle` 可配置；不使用真实时钟或随机运动。
- 共用背景放在 Composition 外层，跨 `Sequence` 保持同一全局帧时钟；片头、片尾组件设置 `showBackground={false}`。需要结尾静止时向外层背景传入 `holdSeconds`，在稳定区开始前最多一秒平滑减速，进入稳定区后位置完全固定。默认样片最后 1.5 秒包含背景在内全部静止。
- 光晕仅靠近当前叙事焦点，透明度约 0.08–0.16，不承担随机运动。
- 竖屏需要重新排版和重新定字号，不把横屏整体缩小或拉伸成交付成片。

## 色彩语义

| 角色         | 默认值                   | 用途                 |
| ------------ | ------------------------ | -------------------- |
| Canvas       | `#030404`                | 基础背景             |
| Panel        | `#0d2035`                | 需要承载信息时的面板 |
| Strong panel | `#102a43`                | 重点区域             |
| Ink          | `#f8fafc`                | 主信息               |
| Muted        | `#91a4bb`                | 辅助说明、来源       |
| Cyan         | `#23c7d7`                | 主流程、主关联       |
| Blue         | `#3c82d6`                | 次级对象、第二分支   |
| Violet       | `#9346b5`                | 第三分支、特殊对象   |
| Green        | `#2dcf8b`                | 已完成、正确结果     |
| Orange       | `#ff7a30`                | 当前焦点、动作、警示 |
| Red          | `#f05252`                | 错误、冲突、风险     |
| Border       | `rgba(255,255,255,0.15)` | 分隔与边框           |

同一对象跨场景保持身份色；当前焦点可用描边、光晕或局部强调表达。对照场景应同时用文字或形状区分，避免颜色成为唯一的信息渠道。科学场景中若物体的真实颜色本身是解释对象，保留真实颜色，并用品牌色呈现标注。

## 字体与字卡

没有现有字体规范时，默认建议中文使用思源黑体，英文标题使用 Space Grotesk，英文正文使用 Inter，代码/数值表使用 JetBrains Mono；这些字体不随模板打包，需要使用目标项目已提供或获授权的字体文件。已有频道字体优先。混合标题按主要语言选字体，独立短英文标签可以分 span。模板中的字体角色需要绑定已实际加载的 family alias。

| 内容层级  | 默认范围 | 说明                  |
| --------- | -------- | --------------------- |
| 开场标题  | 80–108px | 建议两行以内          |
| 章节标题  | 54–68px  | 与正文留出明显间距    |
| 结论字卡  | 46–60px  | 一个主结论，短句优先  |
| 正文图解  | 38–48px  | 让观看距离下仍可读    |
| 标签      | 30–38px  | token、图形与流程节点 |
| 来源/注释 | 26–32px  | 不承载核心解释        |

字号范围是层级，不是长标题挤压规则。长标题优先换行、改布局或经用户授权精简，不缩成小字。模板使用平衡换行，但浏览器不能理解中文词组；在完整词组或标点处用 ReactNode 的显式换行调整，避免把关键词拆到两行。公式上下标、根号和矩阵按数学结构排版，不用字距硬凑。

字卡按职责使用：开场问题、章节导航、重点结论。常规图解不把口播逐句变成大字卡。重点文字最多两个层级，一个场景只保留一个显著焦点；辅助说明保持低对比。

主面板圆角约 22–36px，紧凑标签 6–12px。连接线约 4–7px，端点圆角且方向明确；线绕过文本与卡片。面板仅在分组确实有助理解时出现，画对象和关系可以直接使用 SVG。

## 频道品牌

`video-brand.ts` 是频道身份的唯一配置入口。默认 `channelName`、`logoPath`、`tagline`、`endNote` 都为空；这些是待配置项，而不是示例品牌。

- Logo 使用透明 SVG/PNG 或用户提供的素材，保持纵横比和留白，不裁成圆形、不重绘商标。浅色 Logo 优先匹配深色画布；若现有素材在深色背景不可辨识，说明并选择用户授权的变体。
- 水印落在统一角落，避开标题和来源；正文布局在配置品牌时预留它的占位。模板样片的正文标题区为右上角标记留出横向空间；没有品牌时使用完整宽度。优先低存在感，图解密集时可省略或换到另一个预先确定的锚点。
- 没有 Logo、有频道名时可使用纯文字标记；英文名默认使用正文英文角色，含中文的名称使用中文角色。两者都没有时省略标记。不要拿项目中的第三方产品 Logo 充当频道 Logo。
- 频道短语、关注提示、社交账号、二维码和音效不由技能猜测。配置为空就不输出。

## 片头片尾

默认片头约 2 秒，先呈现本期核心问题，再带出小型频道标记；它不是每节讲解都要重复的动画。短图解、已剪辑时间轴和系列中间节默认省略片头片尾。用户明确要求只做品牌 bumper 时按请求制作。

默认片尾约 3 秒：结论先落定，可呈现最多三个要点和已配置的结束语，最后至少 1.5 秒保持稳定。没有结束语时只呈现知识总结，不虚构关注话术。结尾稳定区不再漂浮、闪动或循环。

缩短模板片尾时，其正时长不能短于所设稳定区；两者等长时结论直接完整显示，省略入场。将片尾时长设为零会同时关闭该片尾与稳定区，独立讲解片段可自行安排内容结尾。

同一完整视频默认共享背景、片头结构和片尾结构，但不能把内容场景的阅读时间挤掉。总时长固定时先分配图解所需时间，再决定是否缩短或省略品牌段。
