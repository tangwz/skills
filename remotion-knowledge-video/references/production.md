# 制作与验收

## 解释结构

先固定回答核心问题的静态图解，再让动效解释它如何形成：

| 关系                 | 图解选择                 |
| -------------------- | ------------------------ |
| 输入经机制得到输出   | 流程、对象转换           |
| 方案或状态差异       | 左右对照，匹配尺度与基准 |
| 数量、概率、尺度变化 | 同坐标系变化或分布       |
| 空间、方向与传播     | 对象、轨迹与标注         |
| 公式来历             | 代入、对齐项与逐步推导   |

类比标明简化范围，颜色、箭头和数值不暗示未经支持的因果。引述、数据和重绘图表提供可追溯来源。

静态布局先扣除底部口播字幕区及内容间距，再安排图解和底部导航。口播稿用于确定讲解节奏，默认不逐句显示或导出为字幕；保持少量解释关系所需的标题与标签。安全区数值和接入方式见 [视觉与品牌规范](visual-identity.md#口播字幕预留区)。

## 动效与时间轴

有口播时先按 [口播时序](narration-timing.md) 建立预算和锚点；批量作品按 [分段规则](batch-transcripts.md) 在每片独立编排。以下是可调整的视觉建议，预算优先：

- 默认缓动 `Easing.bezier(0.16, 1, 0.3, 1)`；常规入场约 0.67–1 秒，透明度 0→1，位移 18–34px→0，缩放 0.96→1。
- 同组错开约 0.27–0.6 秒，关系线生长约 1–1.73 秒，交叉淡化约 0.5 秒。
- 对象出现、关系建立、状态变化、结论落定；每个动作解释关系或变化。轻微 shake 仅表示错误/冲突，正常过程不连续弹跳或旋转。
- 最终结论落定；循环与无限呼吸不作为稳定阅读区。

时间以秒定义，读取实际 fps 换算整数帧。`Sequence` 子组件使用局部帧，父时间轴函数明确接收全局或局部帧，不重复减偏移；进度 clamp，尾段不漂移。用数据关联场景、口播区间、动作开始/完成与稳定区，复杂状态或计算提取纯函数并检查阶段边界。

共用背景、字体与品牌接线见 [项目接入](project-integration.md)；内容使用适合主题的 SVG、图片、公式或数据可视化，不共享全部场景 DOM。样片秒数不决定口播作品片长。

## 检查方式

使用项目实际注册入口、预览与检查命令，按本次作品命名输出，保留旧作品。取首个完整信息画面、核心变化、收尾关键帧，再用 Studio 或片段复查运动和转场。

- **视觉**：字体正确加载、标题换行、安全区、Logo 比例、连接线不穿字、语义色一致；共用组件修改另检查长标题与最宽 Logo 同时出现的画面。
- **连续性**：复查场景边界，排除背景重置、闪黑和残留；移动背景在稳定区前应有实际运动。
- **静止区**：逐帧比较整个区间的实际背景与前景状态或像素；只比较首尾不能排除中间变化。跨 fps 的同秒像素比较声明差异阈值，避免字体光栅化误判。
- **口播**：有录音时连贯试听开场、中段、结尾，检查锚点和媒体结束点；文字估算核对各段预算，注明待校准。静帧不能证明声音同步。

字幕与底部留白单独验收：未明确要求字幕时，正式输出没有口播字幕层或新增字幕文件。检查开场、正文和结尾中最靠下的文字、导航、线条和水印，并覆盖转场及最大位移帧，确保完整可见且未侵入字幕区或其上方间距。可在临时验收预览中叠加预定后期字幕的两行样文，直观看是否遮挡；验收辅助层不进入正式视频或字幕交付物。不能只检查字幕开关为 false，也不能用容器裁切掩盖溢出。

为非平凡时序、计算和错误恢复增加有意义的测试，记录已有失败与本次改动的关系；简单换色或文档不增加源码字符串匹配测试，不为通过检查恢复用户已删除的资源。
