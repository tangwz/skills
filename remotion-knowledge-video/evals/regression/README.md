# 分段与口播时序回归

本目录是确定性测试作品与检查器，不是通用生成器或技能/基线对照。产物生成 agent 不读取本目录及评分断言。

## 环境与命令

用 `package.json` 与完整 `package-lock.json` 安装；运行范围由 `engines.node` 声明为 Node 18.15+（18.x）或 20+。直接依赖相同不代表传递依赖相同，复用项目依赖时另记实际树。测试需要 FFmpeg/ffprobe（含 libx264）；渲染另需 Remotion 浏览器和本地端口权限。

```sh
npm ci --prefix SKILL_PATH/evals/regression
node --test SKILL_PATH/evals/regression/regression.test.cjs
npm run check --prefix SKILL_PATH/evals/regression
node SKILL_PATH/evals/regression/render.cjs OUTPUT_PARENT FONT_DIRECTORY
node SKILL_PATH/evals/regression/render.cjs --resume EXISTING_BATCH_DIRECTORY FONT_DIRECTORY
```

占位符换为实际路径。字体目录包含 `title.woff2`、`body.woff2`、`chinese.ttf`、`mono.woff2`，分别映射四个模板角色；中文使用本地宋体，英文可用 Space Grotesk / Inter / JetBrains Mono。字体不随技能分发，也不链接外部项目。缺失文件在建立批次前失败，浏览器加载失败终止渲染。

中文文件按实际文件头识别 TTF 的 `truetype` 或 TTC 的 `collection`，遵循 [CSS 字体格式提示](https://www.w3.org/TR/css-fonts-4/#font-format-definitions)，不按扩展名猜测；报告记录字体字节哈希和格式。

## 检查覆盖与恢复

快速检查覆盖原稿保留、顶层 Markdown 分段与元数据判别、嵌套口播及换行/行内 HTML、音频整数与小数帧覆盖、绝对边界、实际动作及结果标签、逐帧前景/背景稳定区、输出重名和同版批次恢复。保留提前完成全部动作的负向样本，以及 4.5/5.2/6 字每秒、含/不含停顿的朗读时长估算检查。

普通渲染创建新批次。`--resume` 在写入前核对原 `plans.json` 的计划、字体、渲染实现和依赖快照及缓存字体字节；新批次还记录生成的尾音测试 WAV 哈希，续跑时文件缺失或字节改变则拒绝恢复。续跑重新执行测试与类型检查，并在报告记录当前测试源码哈希，测试文件不参与视频身份绑定。缺少快照或输入改变则使用新目录。完成视频按字节哈希复用，移动批次后刷新路径。

同版输入和运行环境下，续跑复用报告中已验证且字节哈希一致的关键帧与音轨证据。运行环境记录 FFmpeg/ffprobe 完整的版本、构建配置与关联库信息；任一工具信息改变时重新取得媒体证据。缺失或被修改的关键帧单独重绘；音轨验证文件失效时重建音轨检查。缺少有效报告或环境改变时，已完成的视频重新探测、解码，并重新取得关键帧与音轨证据；正文仍只编码未完成段。报告记录复用的关键帧数和音轨状态。

manifest 在首次编码前绑定完整有序计划；增删、重排或改动不能混用旧产物。媒体验证后先持久化带字节哈希的 `ready`，再发布 MP4 并记为 `complete`；manifest 用同目录临时文件原子替换。只恢复与已验证哈希相同的临时/最终文件，不接管未追踪文件。子进程检查发布前后及状态写入中断和文件被修改的情形；这是单写入进程恢复，不证明并发写入或断电耐久性。

## 渲染证据

冻结原稿生成三份不同的 640×360、60 fps MP4，逐文件核对帧数与时长并完整解码，解码错误立即失败。回归还破坏一个保留正确流元数据的视频包，确认不能误报为验证通过。第二段首次故意失败，重试仅编码该段，其他成片哈希不变；显式续跑不再注入失败。

关键帧覆盖开场、动作前后、中部和稳定区首尾。稳定区首尾 PNG 比较与逐帧状态检查分别记录，不能将两张 PNG 称为全区间像素证明。

独立 `audio-coverage/` 用 1.004 秒合成音轨测试尾部覆盖：仅最后 4 毫秒有信号，Remotion 无损混音后一次 AAC 编码，解码核对尾段信号。该测试不模拟口播，也不证明其他编码路径具有相同延迟。

批次保留计划、manifest、测试/类型检查输出、视频、关键帧及自动报告。报告记录输入/评分/实现/字体哈希、环境、预计朗读时长、实际媒体指标和恢复证据；不填主观布局或技能/基线成绩。渲染后检查关键帧可读性，无真实口播不能证明个人语速或声音同步。
