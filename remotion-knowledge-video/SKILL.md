# Remotion 知识视频

共用品牌配置统一视觉，口播决定时间预算；每期图解服务自己的知识命题。

## 任务与修改范围

先检查目标项目的 `AGENTS.md`、依赖、Composition 注册、主题、字体及相关画面。按任务读取必要参考：

- **完整新一期**：安排内容开场、知识图解和结尾总结，可以使用统一片头片尾。
- **讲解片段或系列中间一节**：默认不插入频道片头片尾；适配用户指定的旧片段时保持既有时长和接口。
- **品牌或风格调整**：修改用户指定的共用配置或组件，并检查它们影响的代表性画面。
- **旧视频适配**：保留讲解文案、公式、数据、音频和关键时序，只在已授权范围内调整视觉。
- **整篇逐字稿**：读取 [分段与批量输出](references/batch-transcripts.md)，每个有效段使用独立内容组件、Composition 和从零开始的时间轴。用户要求视频文件时才编码。

**新 session 默认创建新作品**：使用未占用的文件名、导出名和 Composition ID，追加注册并保留旧作；共用品牌层仍复用一份。同一 session 可继续迭代本次作品；用户明确指定编辑、修复或替换旧作时，按指定范围修改。

项目规则与用户要求优先。字幕显示与文件生成按实际控制开关和数据来源处理，不假设项目存在特定字幕文件。未提供频道名或 Logo 时省略对应元素，不阻塞制作。

新视频默认不渲染或烧录口播字幕，也不生成 SRT、VTT 等字幕文件；提供口播稿或音频用于编排动画，不代表要求生成字幕。标题、公式、节点标签和必要的重点字卡属于图解内容，可以正常使用。只有本次请求或目标项目规则明确要求时才启用相应字幕输出；旧视频的已有字幕资产、显示开关和时间轴不因新片默认值而被删除或改写。

无论是否输出字幕，都默认在视频最底部预留口播字幕区，供后期叠加字幕。图解、导航、进度条、来源和水印均在该区域上方排版，动画的完整运动范围也不得进入；背景可延伸到底部。预留比例与内容间距见 [视觉与品牌规范](references/visual-identity.md)，不要用空字幕组件或逐句口播字卡占位。已有作品仅改本次授权范围，不因默认安全区扩展为整片布局迁移。

## 共用品牌与主题画面

读取 [视觉规范](references/visual-identity.md)。复用已有品牌层；首次建立时从 [模板](assets/template/) 复制所需模块及其相对导入依赖。品牌、风格和共用组件各保留一个实现来源，单期文案与差异通过 props 或局部配置注入。仅在用户要求共用风格调整时改动共用层。

首次接入或跨项目复用时读取 [项目接入](references/project-integration.md)，适配真实入口、字体、资源和画布。品牌样片只用于建立或验证共用层，不必每期复制。默认风格未确定的项在交付时说明；不为单期制作改写技能默认模板。频道 Logo 使用用户指定素材，产品或模型 Logo 属于内容素材。

先固定核心问题、结论和静态图解，再安排动效。根据机制、对照、尺度、因果、空间或公式选择布局；统一背景与品牌锚点，不把不同知识主题都塞进同一种卡片墙。

## 视频时长与动画进度

制作画面和动效时读取 [制作与验收](references/production.md)；安排视频时长和动画进度时读取 [口播时序](references/narration-timing.md)。视频总时长应尽量接近口播的实际时长或预计朗读时长。优先依据录音或用户确认的时码安排；只有稿件时，按实际念法、语速和停顿估算朗读时长。

先确定每段讲解的开始和结束时间，再安排对应的画面与动画，让关键变化发生在讲到相应内容的时候。开场、中段和结尾都要跟随讲解进度，不能只让视频总时长接近口播总时长。

片头、正文、转场、片尾和结尾静止画面都计入视频总时长。结尾先让结论和动画落定，再利用总结或已有停顿保持画面稳定，不冻结尚未完成的动作，也不机械追加模板的片头片尾时长。旧视频的既有时序只在本次授权后调整。

新作默认 60 fps，注册读取共用配置；内部绝对秒级边界用 `Math.round(seconds * fps)` 换算，再求相邻区间。录音最终覆盖按 [帧换算规则](references/narration-timing.md#帧换算与检查) 向上取整。混剪核实素材与成片帧率，区分 59.94 与 60 fps；旧作保留原帧率，迁移须换算完整时间轴。

## 用 Remotion 实现

按需使用可用的 `remotion-best-practices`；不存在时根据目标项目版本查官方文档，保留此处的实现边界。使用项目已有依赖和字体加载路径，避免为品牌层额外安装媒体、动效或字体包。

动画由 Remotion 帧驱动，区分 `Sequence` 内的局部帧与 Composition 全局帧。不要使用 CSS animation/transition、真实时钟或非确定性随机效果。资源放在 `public/`，用 `staticFile()` 与 `Img` 引用；字体加载失败应显式报错，不能用不同系统字体悄悄完成最终渲染。

新视频追加注册 Composition，保留已有作品；样片可使用独立临时入口，避免污染用户原有注册。旧视频适配按请求控制影响面，不自动迁移整个作品库。

## 验收与交付

按 [制作验收](references/production.md#检查方式) 检查开场、正文关系建立、核心变化和结尾稳定等关键帧。修改共用组件时至少比较两种内容长度或布局；为复杂时序或数学计算验证边界，不为文档措辞或简单样式编写脆弱测试。

交付包含：可编辑的配置/组件位置、Composition ID、预览或关键帧、验证方式及尚未确定的品牌项。检查背景与字体是否统一、Logo 是否变形/遮挡、文字是否溢出、语义色是否一致、结尾是否可读。仅报告有证据的结果；未渲染时明确说明。

检查底部字幕区在静态和运动过程中是否保持空净，说明字幕输出策略与预留区尺寸。

有口播的作品附逐段时序表、采用的时间依据、口播与视频总时长及差值，区分实测与待校准估算；批量作品按 [分段规则](references/batch-transcripts.md) 交付原稿段落到作品的对应清单。未编码的路径不列为已完成视频文件；未渲染或试听的部分不声称已验证。

改动默认保存到本地。发布、发送、购买素材或生成旁白需要相应任务授权；创建视觉技能不隐含这些动作。

## 示例请求与回归

可直接使用：`使用 $remotion-knowledge-video，为本期主题制作一段延续频道风格的 Remotion 科普视频。`

[evals/evals.json](evals/evals.json) 在完整新一期、已有片段适配、跨学科讲解和共用风格调整四类示例上，补充口播稿估时、按确认时码编排、整篇逐字稿分段及整篇录音的分段时码映射，另有默认不生成字幕、显式要求字幕两个专项回归。按视频时长、动画与讲解进度、分段输出、背景连续性、结尾静止、品牌布局、字幕避让及配置传播等实际结果独立评分，允许等价实现。仅执行或维护评测时读取 [评分说明](evals/evaluation.md)；日常视频制作无需读取。示例的项目约束属于各自输入，不是其他项目的默认规则；旧分数不沿用到修改后的断言。
