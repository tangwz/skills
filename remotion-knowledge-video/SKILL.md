# Remotion 知识视频

共用品牌配置统一视觉，口播决定时间预算；每期图解服务自己的知识命题。

## 任务与修改范围

先检查目标项目的 `AGENTS.md`、依赖、Composition 注册、主题、字体及相关画面。按任务读取必要参考：

- **新一期**：内容开场、知识图解、结尾总结；品牌段纳入口播预算。
- **片段或旧作调整**：默认不加频道片头片尾；保留原文、数据、音频、接口和时序，只修改授权范围。
- **整篇逐字稿**：读取 [分段与批量输出](references/batch-transcripts.md)，每个有效段使用独立内容组件、Composition 和从零开始的时间轴。用户要求视频文件时才编码。
- **共用风格调整**：修改指定的共用配置或组件，复查受影响的代表性画面。

**新 session 默认创建新作品**：使用未占用的文件名、导出名和 Composition ID，追加注册并保留旧作；共用品牌层仍复用一份。同一 session 可继续迭代本次作品；用户明确指定编辑、修复或替换旧作时，按指定范围修改。

项目规则与用户要求优先。字幕显示与文件生成按实际控制开关和数据来源处理，不假设项目存在特定字幕文件。未提供频道名或 Logo 时省略对应元素，不阻塞制作。

新视频默认不渲染或烧录口播字幕，也不生成 SRT、VTT 等字幕文件；提供口播稿或音频用于编排动画，不代表要求生成字幕。标题、公式、节点标签和必要的重点字卡属于图解内容，可以正常使用。只有本次请求或目标项目规则明确要求时才启用相应字幕输出；旧视频的已有字幕资产、显示开关和时间轴不因新片默认值而被删除或改写。

无论是否输出字幕，都默认在视频最底部预留口播字幕区，供后期叠加字幕。图解、导航、进度条、来源和水印均在该区域上方排版，动画的完整运动范围也不得进入；背景可延伸到底部。预留比例与内容间距见 [视觉与品牌规范](references/visual-identity.md)，不要用空字幕组件或逐句口播字卡占位。已有作品仅改本次授权范围，不因默认安全区扩展为整片布局迁移。

## 共用品牌与主题画面

读取 [视觉规范](references/visual-identity.md)。复用已有品牌层；首次建立时从 [模板](assets/template/) 复制所需模块及其相对导入依赖。品牌、风格和共用组件各保留一个实现来源，单期文案与差异通过 props 或局部配置注入。仅在用户要求共用风格调整时改动共用层。

首次接入或跨项目复用时读取 [项目接入](references/project-integration.md)，适配真实入口、字体、资源和画布。品牌样片只用于建立或验证共用层，不必每期复制。默认风格未确定的项在交付时说明；不为单期制作改写技能默认模板。频道 Logo 使用用户指定素材，产品或模型 Logo 属于内容素材。

先固定核心问题、结论和静态图解，再安排动效。根据机制、对照、尺度、因果、空间或公式选择布局；统一背景与品牌锚点，不把不同知识主题都塞进同一种卡片墙。

## 口播预算与实现

制作画面和动效时读取 [制作与验收](references/production.md)；涉及稿件、录音或节奏时读取 [口播时序](references/narration-timing.md)。录音与已确认时码优先，只有文字时按实际念法和语速估算。先建立段落区间与讲解词锚点，再编排动作；总长匹配不能代替中段进度对齐。

片头、正文、转场、片尾和稳定区共用一个预算。结论先落定，稳定区使用剩余总结或停顿时间，不冻结未完成的动作或机械追加模板秒数。固定旧作时序仅在本次授权后调整。

新作默认 60 fps，注册读取共用配置；内部绝对秒级边界用 `Math.round(seconds * fps)` 换算，再求相邻区间。录音最终覆盖按 [帧换算规则](references/narration-timing.md#帧换算与检查) 向上取整。混剪核实素材与成片帧率，区分 59.94 与 60 fps；旧作保留原帧率，迁移须换算完整时间轴。

使用项目现有依赖与字体加载路径；需要时读取可用的 `remotion-best-practices`，或按项目版本查官方文档。动画由 Remotion 帧驱动，区分局部帧与全局帧，不使用 CSS animation/transition、真实时钟或非确定性随机效果。public 资源通过 `staticFile()` 和 `Img` 引用；字体失败应报错，最终渲染不静默回退。

新作追加正常注册，临时品牌样片可使用独立入口。视觉制作不自动授权旁白生成、素材购买或对外发布。

## 验收与交付

按 [制作验收](references/production.md#检查方式) 复查关键帧、运动和布局；共用组件修改检查不同内容长度或布局。复杂时序和计算验证边界，简单样式与文档不增加源码字符串匹配测试。

交付配置/组件位置、Composition ID、预览、验证证据和未确定项。口播作品附逐段时序表、时间依据、口播/视频总长及差值，区分实测与待校准估算；批量清单按 [分段规则](references/batch-transcripts.md) 交付。未编码的路径不列为完成文件，未渲染或试听的部分不声称已验证。

检查底部字幕区在静态和运动过程中是否保持空净，说明字幕输出策略与预留区尺寸。

[评测案例](evals/evals.json) 供技能维护者使用；仅执行评测时读取 [评分说明](evals/evaluation.md)。按产物行为评分，允许等价实现；案例约束不扩展为其他项目的默认规则。
